# 8-Week .NET Full Stack Sprint Interactive Tracker

An interactive single-page web tracker for mastering .NET Core, Web APIs, EF Core, Microservices, Angular, Azure, and DSA in 8 structured weeks.

## Features
- **Accordion Navigation:** Click any week card to expand core syllabus, topics, and daily checklist.
- **Dynamic Circular Progress:** Live animated SVG green progress circles with percentage per week.
- **Milestone Rewards:** Animated Party Popper (`🎉`) upon completing all 6 days of any week.
- **Full Persistent Storage:** All ticks, progress, and accordion states auto-saved locally in browser `localStorage`. Refreshing or revisiting the page never resets or loses your data.
- **Vercel Ready:** Static single-page application ready to deploy instantly.

## Deployment to Vercel
1. Import this repository in [Vercel](https://vercel.com/new).
2. Framework Preset: **Other**.
3. Click **Deploy**.
